Report of Progress

What is it?

This iDevice is shows the results obtained by the student in the activities associated with the same and its average note. 

With this iDevice, we will be able to collect the qualifications of the activities we select and present them in a final report that can be saved as an image.

Examples of use

How is it done?

When selecting the iDevice "Progress Report" from the iSpeed list, the following will be shown in our eXeLearning:

In the top, we will have the possibility to modify the title and assign an icon, once the iDevice is saved. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our report.

General Adjustments

In the "Options" section we will enter the identifier that determines which activities will appear qualified in the report. In advance, we will have entered this same identifier in such activities. We will also add the number of evaluable activities. In addition, we will be able to configure this report with different options: show date and time, show the type of iDevice, link the activities and enter user data.
