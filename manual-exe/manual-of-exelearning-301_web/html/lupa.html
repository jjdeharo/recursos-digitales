Lupa

What is it?

This iDevice can be used to see parts of an enlarged image.The corresponding image must be provided and the level of enlarge and size of the lupa is selected.The image will be enlargen when passing over it with the mouse.

Examples of use

Choose the level of increase and the size of the lupa. The image will be expanded when passing over it with the mouse.

The image is not available

The full screen

How is it done?

By adding the iDevice we open a text box where we can detail the corresponding instructions we are looking for in a particular activity:

Now we are opening the possibility of uploading an image that will be the one we can use to, expand with lupa and see details (e.g. a picturesque work). We can decide, the width of the image, its alignment, the increase in start and the size of lupa. These two last options can also change in the published iDevice.
