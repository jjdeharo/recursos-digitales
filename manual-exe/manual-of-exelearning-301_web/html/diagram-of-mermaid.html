Diagram of Mermaid

What is it?

This option allows you to incorporate a diagram made with Mermaid into our content.

How is it done?

To add a diagram created with Mermaid we will follow the following steps:


  • In the editor menu, go to Insert > Diagram Mermaid
  • In the dialog box, we write the code.
  • Click to save.
  • The diagram will be seen when you save the iDevice.
