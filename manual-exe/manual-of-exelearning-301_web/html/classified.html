Manual of eXeLearning 3.0.1

Classified

What is it?

We will use this device for Create games where players will have to classify cards with images, texts and/or sounds. different categories previously created.

Depending on the level of difficulty the games will be able to create games with different options:

  • level BasicThe card can be placed in any category, warns if it is right or wrong with green or red color respectively on the edges and gives a message of correct or error that can be customized.
  • level The MiddleThe card can be placed in any category allowing the mobility of the cards. By clicking on Check, the results and score will be viewed.
  • level advanced: Once placed the card in a category is immovable. Notify if it is good or bad with green or red color respectively on the edges and gives a message of correct or error that can be customized.

How is it done?

When selecting the iDevice "Classification" from the list of iDivices, the following will be shown in our eXeLearning:

In the top, we will have the possibility to modify the title and assign an icon, once the iDevice is saved. Last, we’ll have the option to include a subsequent content. We see that there are a number of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Adjustments


The "General Adjustments" tab is the one that is displayed by default when creating the Classical iDevice.

In this tab we will define the instructions to perform the game, the different options and settings available and the questions with the clues we determine.

  • By clicking on the "Instruktions" section, a text box will be opened where we will be able to specify the instructions to follow.
  • By clicking on the "Options" section we will be able to decide the level of complexity of the game (basic, medium or advanced), add, or not, "Personalized Messages", define up to a number of four the names of the categories of what we want to classify, if we want it to show minimal start, game time, the feedback option that allows to define the message to return, the percentage of Questions to overcome the game, the authority and the option to mark the Progress Report with your corresponding identifier.
  • In the "Tags" section, for each of them we will be able to introduce:
    • The text / image / audio of the first card with its corresponding group.
    • The text / image / audio of the second card with its corresponding group.
    • Third, fourth and so on.

Contrasigns

In the "Contrasigns" tab, we will be able to create a challenge itinerary in which players will not be allowed to access a new game until they get a key in a previous activity. For this, we can set up an access code as well as a message that will be shown to players when they reach a fixed percentage of accidents, and that they will be allowed for use as a password for a new challenge or a subsequent activity. 

Both are optional, and your configuration will only appear if we mark them, as in the image.

Scorry

In the "SCORM" tab we will be able to determine if we want to save the results obtained by our students and in what conditions we want it to do when we export our contents.

It should be noted that this option of storage It will only be available for SCORM exports and when we publish our content on platforms such as: by Moodle or other LMS platforms compatible with SCORM.

personalized texts

Table where we will be able to customize the automatic texts and messages that the iDevice generates.

Import and Export

In the “Import/Export” tab we can imported Questions compatible with this activity from txt or xml files (Moodle), or we can Exporting Questions in txt format to integrate them into other compatible activities.

IA

This tab allows you to bring questions from an AI chatbot in a simple way. So when opening it is shown to us, as an example a Prompt (model) that we can take to a chatbot that will generate questions in the appropriate format to be paste on the "Questions" tab. These questions proposed by AI will be added to the iDevice when we save ready to be used in the activity.
