What is it?

We will use this device for Create games in which players will have to order, phrases or cards with images, texts and/or sounds

Depending on the option we choose to order phrases or elements there will be one or another possibilities.

  • It is used to order a phrase that has been provided to the disordered user.
  • It is similar to the previous but with two possibilities:
    • Order multimedia elements that are disordered. 
    • Order multimedia elements that are disordered by fixing the head so that under this the rest is ordered.

How is it done?

When selecting the iDevice "Order" from the list of iDivices, the following will be shown in our eXeLearning:

In the top, we will have the possibility to modify the title and assign an icon, once the iDevice is saved. Last, we’ll have the option to include a subsequent content. We see that there are a number of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Adjustments


The "General Adjustments" tab is the one that is displayed by default when creating the Order iDevice.

In this tab we will define the instructions to perform the game, the different options and configurations available.

  • By clicking on the "Instruktions" section, a text box will be opened where we will be able to specify the instructions to follow.
  • By clicking on the "Options" section we will be able to decide whether we will choose to order "frases" or "multimedia"
The Options (Frases)
  • In the option.”phrases"We will decide if it is shown minimized the start, the game time and the possibility of showing or not the solutions, the feedback option that allows you to define the message to return, the percentage of questions to overcome the game, the authority and the option to mark the Progress Report with your corresponding identificator.
  • In the section "Activities" option "Frases" we will be able to enter the phrase chosen to order
The Multimedia (Multimedia)
