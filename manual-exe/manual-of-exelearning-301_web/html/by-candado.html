How is it done?

When selecting the iDevice "Candated" from the list of iDivices, the following will be shown in our eXeLearning:

On the top, we will have the possibility to modify the title and assign an icon, once the iDevice is saved.We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Adjustments

The "General Adjustments" tab is the one that is displayed by default when creating the Candado iDevice.

In this tab we will offer the instructions of the activity, as well as the feedback that will be offered once the correct access code is indicated. 

This access code will be defined as well as the time available to enter it and you will be able to set the possibility of repeating the activity and the number of errors that will be permitted before the error message is displayed.

    personalized texts

    Table where we will be able to customize the automatic texts and messages that the iDevice generates.

    Scorry

    In the "SCORM" tab we will be able to determine if we want to save the results obtained by our students and in what conditions we want it to do when we export our contents.

    It should be noted that this option of storage It will only be available for SCORM exports and when we publish our content on platforms such as: by Moodle or other LMS platforms compatible with SCORM.
