General Adjustments


The "General Adjustments" tab is the one that is displayed by default when creating the iDevice Map.

In this tab we will define the instructions to perform the game, the different settings and evaluation options available and the interactive activities and areas of the image we use.

  • By clicking on the "Options" section we will be able to choose the type of activity or map evaluation we will create: Visited points, Identifying, Searching, Identify points, Questionary and Order.
  • In the "Map" section, once selected the type of evaluation - activity, we will have the option of:
    • Introduce a picture.
    • Enter an icon on that image that results in an information in the form of text, image, video, audio, presentation or another new map or interactive image. We will add a new point to the map by clicking on + 
    • In the event that you have selected the activity - evaluation type Questionnaire, you will show us a new field in which to create questions such as Select, Order or Word, similar to those of the iDevice Selecciona.

Contrasigns

In the "Contrasigns" tab, we will be able to create a challenge itinerary in which players will not be allowed to access a new game until they get a key in a previous activity. For this, we can set up an access code as well as a message that will be shown to players when they reach a fixed percentage of accidents, and that they will be allowed for use as a password for a new challenge or a subsequent activity. 

Both are optional, and your configuration will only appear if we mark them, as in the image.
