Discovered

What is it?

We will use this device for Create games in which players will have to discover couples, trios or quarters of cards with images, texts and/or sounds.

According to the level of difficulty the games will be able to create games with different options, equal for couples, trios or quarters:

  • level The initial: Enable to play directly without the middle level or advanced screen option
  • level The Middle: It allows you to play directly with the initial or advanced level option on screen
  • level advancedIt allows you to play directly with options from any level on the screen.

In this tab we will define the instructions to perform the game, the different options and configurations available.

  • By clicking on the "Instruktions" section, a text box will be opened where we will be able to specify the instructions to follow.
  • By clicking on the "Options" section we will be able to decide if it is shown minimized the start, choose the type of game (parts, trials or quarters) and the difficulty level of 1 to 3, the option to keep the cards visible for a certain time, the possibility to customize the error or correct messages, the time of game or the number of attempts. It is also possible to show or not the solutions, the feedback option that allows you to define the message to return, the percentage of questions to overcome the game, the authority and the option to mark the Progress Report with your corresponding identificator.
  • In the "Parejas" section and according to our choice by couple, trio or quarter, for each of them we will be able to introduce:
    • The text / image / audio of the first couple, trio or quarter.
    • The text / image / audio of the second pair, trio or quarter.
    • Third, fourth and so on.

Contrasigns

In the "Contrasigns" tab, we will be able to create a challenge itinerary in which players will not be allowed to access a new game until they get a key in a previous activity. For this, we can set up an access code as well as a message that will be shown to players when they reach a fixed percentage of accidents, and that they will be allowed for use as a password for a new challenge or a subsequent activity. 

Both are optional, and your configuration will only appear if we mark them, as in the image.

Scorry

In the "SCORM" tab we will be able to determine if we want to save the results obtained by our students and in what conditions we want it to do when we export our contents.

It should be noted that this option of storage It will only be available for SCORM exports and when we publish our content on platforms such as: by Moodle or other LMS platforms compatible with SCORM.

Import and Export

In the “Import/Export” tab we can imported Questions compatible with this activity from txt or xml files (Moodle), or we can Exporting Questions in txt format to integrate them into other compatible activities.

IA

This tab allows you to bring questions from an AI chatbot in a simple way. So when opening it is shown to us, as an example a Prompt (model) that we can take to a chatbot that will generate questions in the appropriate format to be paste on the "Questions" tab. These questions proposed by AI will be added to the iDevice when we save ready to be used in the activity.
