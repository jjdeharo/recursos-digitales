The mental map

What is it?

With this option we will be able to create simple mental maps. Starting from a word or idea, you can go adding as many nodes and subnodes as we want. We can also configure the format of the source and lines. Before incorporating it into our material we will have to give it a name and we will can cut the image.

How is it done?

  • By clicking on the mental map icon  A first window with the map data (Title, Dimensions, Options...). Once filled, we will click on "Open the Mental Maps Editor".
  • Then we can create our mental map. From the central idea (which we can rename by double-click) we will go creating as many branches as we want. We can create and delete branches with the Add and Delete buttons. In addition, from the Inspector panel we will be able to modify the size, style and color of text, as well as the color of the lines.
  • By saving we will be able to decide if we cut the image and define the proportion.
  • Finally, we will return to the initial window and click Accept.
