and tooltip (tooltip)

What is it?

The tooltip allows you to include comments throughout the text, and you can define your appearance and behavior.

“One The tooltip (also referred to as an emergency description) is a tool of Visual AssistanceIt works by placing the cursor on some graphic element, showing an additional help to inform the user of the purpose of the element on which it is located. Wikipedia

Keep in mind that you should not abuse the "Bocadillo" effects. You don't have to make them very extensive or put very wide images. The ToolTip only admits a width below 300 px. 

The graphic user interface, also known as GUI (Graphical User Interface) is a computer program that acts from user interface using a set of images and graphic objects to represent the information and actions available on the interface. Its main use consists in providing a simple visual environment to allow communication with the operating system of a machine or computer.

A tooltip (also called emerging description) is a visual help tool, which works when placing the cursor on some graphic element, showing an additional help to inform the user of the purpose of the element on which it is located.

How is it done?

Create a tooltip  In a text of a content it will be very simple.


  • We select the text to which to add information and click on the Tootltip icon.
  • We choose one of the two options available:
    • Link: to include a hyperlink
    • Definition: to add a text
  • We fill out the requested data
  • In the other tabs we can configure the behavior of the snack and its appearance.
