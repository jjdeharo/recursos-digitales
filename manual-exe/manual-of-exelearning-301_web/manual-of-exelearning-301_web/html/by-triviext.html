How is it done?

When selecting the iDevice "TriviExt" from the list of iDivices, the following will be shown in our eXeLearning:

In the top, we will have the possibility to modify the title and assign an icon, once the iDevice is saved. Last, we’ll have the option to include a subsequent content. We see that there are a number of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Adjustments


The "General Adjustments" tab is the one that is displayed by default when creating the iDevice TriviExt.

In this tab we will define the instructions to perform the game, the different configurations and options available and the questions to select the answer or order of correct answers or expressions and words that our students must know from a definition.

  • By clicking on the "Instruktions" section, a text box will be opened where we will be able to specify the instructions to follow.
  • By clicking on the "Options" section we will be able to configure the number of themes in which we will categorize the questions, the option to show the minimized game, the possibility that the solutions to the questions are shown for a certain time and the option mark the Progress Report with your corresponding identificator.
  • In the Questions section we will have the option of:
    • Defining the name of the topics, categories or "quests" in which the questions that we will later create will be displayed.
    • Choose the game system: select several answers (Selection), order the answers, or guess a word (Word). Like the iDevice Select, we will be able to choose the type of multimedia element, as well as the number of options and time per question.. In the case of choosing "Word" as a game system, you will be possible to set up the percentage of letters to display and the time of question.

We should be very aware that the questions with your answers will be assigned to the topic or category in which we have created them. We can change them or category of questions by clicking on the number box.

Don't worry if you've been confused by creating a question in a category incorrectly You can copy the question, change category and paste it in the right category!

Contrasigns

In the "Contrasigns" tab, we will be able to create a challenge itinerary in which players will not be allowed to access a new game until they get a key in a previous activity. For this, we can set up an access code as well as a message that will be shown to players when they reach a fixed percentage of accidents, and that they will be allowed for use as a password for a new challenge or a subsequent activity. 

Both are optional, and your configuration will only appear if we mark them, as in the image.

Scorry
