Manual of eXeLearning 3.0.1

Complete

What is it?

We will use this device for Create activities in which the student must complete the holes of a text by writing, selecting or dragging the answers..

Given the flexibility of this iDevice, we will be able to create up to four different classes of activities:

  • Complete (writing the word or chain of words)
  • Rush (rushing the words to your corresponding hole)
  • Select (selecting a word from the scatterable box from all hidden words)
  • Select (limiting the words of each scrollable table)

General Adjustments


The "General Adjustments" tab is the one that is displayed by default when creating the Complete iDevice.

In this tab we will define the instructions to perform the game, the different options and configurations available and the texts with holes.

  • By clicking on the "Instruktions" section, a text box will be opened where we will be able to specify the instructions to follow.
  • By clicking on the "Options" section we will be able to decide the type of game (Complete, Arrange, Select and Select by limiting the words of each displaysable box), the number of attempts, the time, if we show the solutions, whether we allow errors, whether it distinguishes between major or not, proportionate sizes of the holes to the words they hide, whether you show the game minimized or simply if We give some kind of feedback when we get a percentage of good at the end of the game. 
  • In the Text section, once introduced the same accompanied by images, videos or any other resource that the eXeLearning editor provides us, we will hide the words or text chains we want to make use of the double drop at the beginning and end of each word or chain to hide.

Contrasigns

In the "Contrasigns" tab, we will be able to create a challenge itinerary in which players will not be allowed to access a new game until they get a key in a previous activity. For this, we can set up an access code as well as a message that will be shown to players when they reach a fixed percentage of accidents, and that they will be allowed for use as a password for a new challenge or a subsequent activity.
