How is it done?

When selecting the iDevice "Geogebra" from the list of iDivices, the following will be shown in our eXeLearning:

In the top, we will have the possibility to modify the title and assign an icon, once the iDevice is saved. Last, we’ll have the option to include a subsequent content. We see that there are a series of options each with a different functionality that will allow us to configure our game in a very flexible way

  • In the "Instruktions" section we will write the text with the instructions to perform the activity.
  • In the "General Configuration" section we will include the URL of the activity created with Geogebra. 

by CEDEC. Configuration of Geogebra (CC by-SA)

  • In the "Advanced Options" section we can see more viewing options, which involves the option to save score or to be included in the Progress Report (see iDevice "Progress Report").
