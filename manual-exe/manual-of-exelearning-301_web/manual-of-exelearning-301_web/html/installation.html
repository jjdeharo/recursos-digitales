Installation

by eXeLearning It offers a remarkable Flexibility in its implementationIt allows you to work so much with Offline (offline) and online versionsThis duality has already been a significant hit with version 2.9, which marked the first time that simultaneously a desktop version and an online version with practically identical functionalities were released.


version of writing

As for the Offline version (offline version)Installers are available for Linux, Windows and MacOS directly on the page of Download from the eXelearning website From the page of Releases GitHub. simply you should choose the right download according to the operating system used.


The Online Version

eXeLearning can easily be installed on a server thanks to a simple displays through DockerThis makes the process a lot more simple, with one command. by docker run It is possible to raise a local environment and begin to create content. by docker exec to access the application from http://localhost:8080. for more details, you can consult the Instructions Complete in the project repository.

In addition, for those who wish to explore the online version and their collaborative capabilities in real time — one of the great novelty of the version 3, there is a The public demo It is important to keep in mind that this demo does not store the data: everything created is lost when closing the session.
