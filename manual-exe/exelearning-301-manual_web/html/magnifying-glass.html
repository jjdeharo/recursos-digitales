eXeLearning 3.0.1 Manual

Magnifying glass

What is it?

This iDevice can be used to view parts of an image enlarged. You must provide the corresponding image and choose the zoom level and the size of the magnifying glass. The image will appear enlarged when you hover over it with the mouse.

Usage example

Choose the zoom level and the size of the magnifying glass. The image will appear enlarged when you hover over it with the mouse.

The image is not available

Full screen

How is it done?

When adding the iDevice, a text box opens where we can detail the corresponding instructions we are looking for in a specific activity:

Now we have the option to upload an image that we can use to zoom in with the magnifying glass and see details (for example, of a painting). We can decide the width of the image, its alignment, the initial zoom, and the size of the magnifying glass. These last two options can also be changed in the published iDevice.
