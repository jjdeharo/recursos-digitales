Guess

What is it?

We will use this iDevice to create an activity or game in which, given the definition of a word, our students are asked for the word itself by completing the missing letters. The definition can be accompanied by images or videos to help students answer correctly.

How is it done?

When selecting the "Guess" iDevice from the list of iDevices, various options will be displayed to us.

At the top, we will have the possibility to modify the title and assign an icon, once the iDevice is saved. Finally, we will have the option to include subsequent content. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way. 

General Settings


The "General Settings" tab is the one displayed by default when creating the Guess iDevice.

In this tab we will define the activities proposed in the iDevice, instructions for carrying out the game, the different configurations and options, and the definitions of the words or expressions that our students should know.

  • When clicking on the "Instructions" section, a text box will open where we can state the instructions to follow.
  • When clicking on the "Options" section, we can configure the maximum time we give our students to answer each question, the percentage of letters to show, show the solutions in each question, as well as whether we want to shuffle the questions in each execution, the scoring system, or if we want to minimize the iDevice. It is also possible to decide whether we want to use the Digital Whiteboard mode and the option to mark the Progress Report with its corresponding identifier.
  • In the Words/Expressions section, we will have the option to write the words and expressions with their corresponding definition, with the possibility of including audio, video, or images. We have four "multimedia" options: None, Image, Video and Text.

In the case of entering a video, the steps should be:

  1. Enter the URL of the video to be inserted.
  2. Click the Play button for the video to start playing (the video time will be shown on the gray button).
  3. Be able to play only a fragment of the video. To do this, we will do the following:
    1. To indicate the start time, we will stop the video at the exact point where we want to start (the time will appear on the gray button). Then, we will click "Start" (it will be marked with a blue border) and then press the gray time button. 
    2. To indicate the end time, we will stop the video at the exact point where we want to finish (the time will appear on the gray button). Then, we will click "Start" (it will be marked with a blue border) and then press the gray time button. 
  4. We can also mute a part of the video, indicating the start time and the duration.

Passwords

In the "Passwords" tab, we can create a challenge itinerary where players cannot access a new game until they obtain a key in a previous activity. For this, we can set an access code as well as a message that will be shown to players when they reach a fixed percentage of correct answers, and which they can use as a password for a new challenge or a subsequent activity. 

Both are optional, and their configuration will only appear if we mark them, as in the image.

SCORM

In the "SCORM" tab, we can determine whether we want to save the results obtained by our students and under what conditions we want to do so when we export our content.

It should be noted that this save option will only be available for SCORM exports and when we publish our content on platforms such as Moodle or other SCORM-compatible LMS platforms.

Custom texts

Tab where we can customize the texts and automatic messages generated by the iDevice.

Import/Export

In the "Import/Export" tab we can import questions compatible with this activity from txt or xml files (Moodle), or we can export the questions in txt format to integrate them into other compatible activities.

AI

This tab allows bringing questions from an AI chatbot in a simple way. When opened, it shows us, as an example, a Prompt (model) that we can take to a chatbot which will generate the questions in the appropriate format to be pasted into the "Questions" tab. These questions proposed by the AI will be added to the iDevice when we save them, ready to be used in the activity.
