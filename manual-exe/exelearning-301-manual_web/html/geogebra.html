eXeLearning 3.0.1 Manual

Geogebra

What is it?

This iDevice allows us to include a task developed with the mathematical software Geogebra. The activity will be hosted on GeoGebra servers, and the end user will only be able to see it if they have an internet connection.

Usage example

In the exercises, click the correct option.

How is it done?

When selecting the "Geogebra" iDevice from the list of iDevices, the following will be displayed in our eXeLearning:

At the top, we will have the option to modify the title and assign an icon, once the iDevice is saved. Finally, we will have the option to include subsequent content. We see that there are a series of options, each with a different functionality that will allow us to configure our game in a very flexible way.

  • In the "Instructions" section, we will write the text with the instructions for carrying out the activity.
  • In the "General Configuration" section, we will include the URL of the activity created with Geogebra. 

Cedec. Geogebra Configuration (CC BY-SA)

  • In the "Advanced Options" section, we can see more display options, which include the option to save the score or to be included in the Progress Report (see iDevice "Progress Report").
