eXeLearning 3.0.1 Manual

Export and downloads

Download options

eXelearning facilitates downloading the created materials in different formats, allowing them to be used in various ways and in different contexts. There are some differences between the desktop and online versions, so we will look at them

Desktop version

In this case, we will have access to our computer to save the .elpx file. We will be able to export the content in various formats:


Available export formats:

  • Website: generates a compressed file (.zip) containing the material organized into web pages. To view it, you need to unzip the file and double-click the file index.html, located at the root of the package.
  • Export to folder (uncompressed website): exports the project files and folders to the folder you specify on your computer.
  • Single Page: downloads a compressed file (.zip) that includes all the content on a single web page. As with the previous format, you must unzip and open the file index.html.
  • SCORM 1.2: widely used educational standard for publishing content on LMS platforms. It includes the project content and metadata and allows tracking of student progress and grades. To view it, it must be uploaded to an LMS that supports SCORM, such as Moodle. It is the recommended version for this type of platform.
  • IMS Content Package (IMS CP): standard compatible with LMS platforms, which includes content and metadata. Unlike SCORM, it does not allow tracking progress or collecting grades.
  • ePub3: open format for e-books. Unlike PDF, ePub files do not have a fixed page size, as the content adapts to the screen size of the device. On small screens it will be displayed on more pages, and on large screens, on fewer.

Print

If we want to print or save our resource as a PDF, we can use the "Print" option that appears in the eXeLearning menu. In the window that opens when we click Print, we will select a printer (if we want to print it on paper) or the Save as PDF option (if we want to save it in this format).

In any case, we must remember that eXeLearning facilitates the creation of interactive content and that, whether printed or saved as a PDF, the interactivity and multimedia resources disappear.
