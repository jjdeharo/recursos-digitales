Mermaid diagrams

What is it?

This option allows incorporating a diagram made with Mermaid into our content.

gantt
    title A Gantt Diagram
    dateFormat YYYY-MM-DD
    section Section
        A task          :a1, 2014-01-01, 30d
        Another task    :after a1, 20d
    section Another
        Task in Another :2014-01-12, 12d
        another task    :24d

How is it done?

To add a diagram created with Mermaid we will follow these steps:


  • In the editor menu, go to Insert > Mermaid Diagram
  • In the dialog box, we write the code
  • We click Save.
  • The diagram will appear when saving the iDevice.
