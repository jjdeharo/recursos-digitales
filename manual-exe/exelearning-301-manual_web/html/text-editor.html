Text editor

Basic text editor elements

2

The eXeLearning text editor is TinyMCE, a WYSIWYG editor (what you see is what you get) open source for HTML. This editor is the fundamental interface for entering and editing textual content within most iDevices.

It offers a main menu with additional functionalities (Edit, Insert, Format, Table, Utilities) and three rows of tools with various options that can be seen in the following image by hovering over the active areas of it.

A first row of tools for basic text editing, such as bold, italics, formatting, font size and type, and text or background color. Its operation is similar to that of any word processor, facilitating the incorporation of various materials.

The text editor has a second row that includes tools for formatting paragraphs (alignment, line breaks, bulleted and ordered lists, definition lists) and for inserting or removing hyperlinks and indents or quotes.

The third row expands its capabilities by allowing the inclusion of texts from other sources, codes (HTML, mathematical markup in LaTeX, syntax highlighting), dynamic effects (accordion, tabs, carousel) and multimedia elements such as images, videos, audios (recorded directly) and musical notation. Its ability to manage content pasting is crucial, offering options to paste plain text and thus avoid "junk" code, which is essential for maintaining HTML cleanliness and facilitating the creation of accessible content.

This icon allows you to put the editing area in full screen and return to the reduced view.

Copy - Paste

In eXeLearning we can copy and paste any textual content using the keys Ctrl+C, Ctrl+X and Ctrl+V. However, it is necessary to keep in mind that, when pasting external content, you can drag "junk" code from the original document that can cause problems later when modifying the format.

To avoid this, the "Paste without formatting" option is activated by default, so that, once the text is pasted from the Clipboard, you can apply the desired format or include links directly from the text editor.

If we need to paste with formatting occasionally, we can deactivate this option by clicking on the corresponding icon. We recommend in this case to clean the code by selecting the text and clicking on from the Main menu > Format > Clear formatting.

Remember that "Paste without formatting" pastes the text without the original formats, links or styles BUT it ensures that the text you are pasting is clean from an HTML point of view. It will not give you problems if you want to format it or apply a style.
