Wheel

What is it?

We will use this iDevice to create an activity or game in which, given the definition of a word, our students are asked for the word itself that begins with or contains the letter indicated in the wheel. The definition or clue can be accompanied by images to help students answer correctly.

How is it done?

When selecting the "Rosco" iDevice from the list of iDevices, the following will be displayed in our eXeLearning:

At the top, we will have the option to modify the title and assign an icon, once the iDevice is saved. Finally, we will have the option to include subsequent content. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Settings


The "General Settings" tab is the one displayed by default when creating the Rosco iDevice.

In this tab we will define the activities proposed in the iDevice, instructions for carrying out the game, the different configurations and options, and the definitions of the words or expressions that our students should know.

  • By clicking on the "Instructions" link, a text box will open where we can state the instructions to follow.
  • By clicking on the "Options" link we can configure the maximum time we give our students to complete the game, the number of turns around the wheel, show the solutions for each question, whether we want to minimize the iDevice and the option to mark the Progress Report with its corresponding identifier.
  • In the "Words" link we will have the option to write the words and their definition. With the icon  the word we have defined that begins with the letter (A, in this case) will be requested. We can ask based on the definition, for a word that contains the letter of the row we are clicking on the icon . Similarly, we can add an image to accompany each word by clicking on the icon 

Passwords

In the "Passwords" tab, we can create a challenge itinerary in which players cannot access a new game or challenge until they obtain a key in a previous activity. For this, we can set an access code as well as a message that will be shown to players when they reach a fixed percentage of correct answers, and which they can use as a password for a new challenge or a subsequent activity.

Both are optional, and their configuration will only appear if we mark them, as in the image.

SCORM

In the "SCORM" tab, we can determine whether we want to save the results obtained by our students and under what conditions we want to do so when we export our content.

It should be noted that this save option will only be available for SCORM exports and when we publish our content on platforms such as Moodle or other SCORM-compatible LMS platforms.

Custom texts

Tab where we can customize the texts and automatic messages generated by the iDevice.

Import/Export

In the "Import/Export" tab we can import questions compatible with this activity from txt or xml files (Moodle), or we can export the questions in txt format to integrate them into other compatible activities.

AI

This tab allows bringing questions from an AI chatbot in a simple way. When opened, it shows us, as an example, a Prompt (model) that we can take to a chatbot which will generate the questions in the appropriate format to be pasted into the "Questions" tab. These questions proposed by the AI will be added to the iDevice when we save them, ready to be used in the activity.
