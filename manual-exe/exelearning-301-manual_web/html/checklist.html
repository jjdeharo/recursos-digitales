eXeLearning 3.0.1 Manual

Checklist

What is it?

With this iDevice we can introduce a checklist to provide a structured and easy-to-understand list of the activities proposed throughout the educational resource. It will be a useful tool for students' self-regulation of learning, allowing them to track the activities they are completing.

We can configure the checklist with sections and subsections so that students can mark completed activities, select the activity status from a dropdown, or enter text content. Upon completion, the report can be downloaded in png format.

Usage example

Complete the checklist by checking the boxes when performing the corresponding activities.

How is it done?

When selecting the "Progress Report" iDevice from the list of iDevices, the following will be displayed in our eXeLearning:

At the top, we will have the option to modify the title and assign an icon, once the iDevice is saved. Finally, we will have the option to include subsequent content. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our checklist.

General Settings

In the "Options" section, we will enter the Title and subtitle of the checklist. We can configure different options: show user data, remember checked options, assign scores, include a logo or decorative images... We can configure our checklist by including activities of different types:

  • Checkbox: A checkbox will appear for the student to mark when they have completed the specified activity
  • Text: A checkbox will appear for the student to mark when they have completed the specified activity and a text box to enter content.
  • Select: The student must select from a dropdown whether the activity is done, in progress, or not completed.
  • No mark: Only text is presented, with no option to mark or enter content. This option is recommended for section or subsection titles, for example.
