eXeLearning 3.0.1 Manual

Identify

What is it?

We will use this iDevice to create activities in which, with the help of a variable number of clues, the player must discover a character, an object, or the solution to a problem.

Given the flexibility of this iDevice, we can create up to two different types of activities:

  • Identify normal mode (any available clue can be accessed without loss of score)
  • Identify advanced mode (score is subtracted for each clue shown)



Usage example

Find the names of four famous philosophers. For this, you have several clues and three attempts for each character.

How is it done?

When selecting the iDevice "Identify" from the list of iDevices, the following will be displayed in our eXeLearning:

At the top, we will have the option to modify the title and assign an icon, once the iDevice is saved. Finally, we will have the option to include subsequent content. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Settings


The "General Settings" tab is the one displayed by default when creating the Identify iDevice.

In this tab we will define the instructions for playing the game, the different options and configurations available, and the questions with the clues we determine.

  • When clicking on the "Instructions" section, a text box will open where we can state the instructions to follow.
  • By clicking on the "Options" section, we can decide whether to show the game minimized, whether to activate the advanced game mode that deducts points from the student each time a clue is shown (if the advanced mode is not activated, the student can access all clues and their final score will not be affected), whether to show questions randomly, whether to show personalized messages, the solutions and time, specific feedback upon completing the game if they have reached a certain percentage of correct answers, the number of questions to display in the game, and finally the option to mark the Progress Report with its corresponding identifier.
  • In the "Questions" section, for each one we can enter:
    • The statement or message of the question.
    • The solution.
    • A related image.
    • The number of attempts allowed to answer the question.
    • The number of hints accompanying each question.

Passwords

In the "Passwords" tab, we can create a challenge itinerary where players cannot access a new game until they obtain a key in a previous activity. For this, we can set an access code as well as a message that will be shown to players when they reach a fixed percentage of correct answers, and which they can use as a password for a new challenge or a subsequent activity. 

Both are optional, and their configuration will only appear if we mark them, as in the image.

SCORM

In the "SCORM" tab, we can determine whether we want to save the results obtained by our students and under what conditions we want to do so when we export our content.

It should be noted that this save option will only be available for SCORM exports and when we publish our content on platforms such as Moodle or other SCORM-compatible LMS platforms.

Custom texts

Tab where we can customize the texts and automatic messages generated by the iDevice.

Import/Export

In the "Import/Export" tab we can import questions compatible with this activity from txt or xml files (Moodle), or we can export the questions in txt format to integrate them into other compatible activities.

AI

This tab allows bringing questions from an AI chatbot in a simple way. When opened, it shows us, as an example, a Prompt (model) that we can take to a chatbot which will generate the questions in the appropriate format to be pasted into the "Questions" tab. These questions proposed by the AI will be added to the iDevice when we save them, ready to be used in the activity.
