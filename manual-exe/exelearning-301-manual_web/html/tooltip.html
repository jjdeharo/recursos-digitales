eXeLearning 3.0.1 Manual

Tooltip

What is it?

The Bubble or tooltip allows including comments throughout the text, being able to define its appearance and behavior.

"A tooltip (also called a pop-up description) is a visual aidtool, which works by placing the cursor over a graphical element, showing additional help to inform the user of the purpose of the element it is over." Wikipedia

Keep in mind that you should not overuse "Bubble" effects. They should not be made very extensive nor should very wide images be placed. ToolTips only support a width below 300 px. Keep this in mind. 

The graphical user interface, also known as GUI (from the English Graphical User Interface) is a computer program that acts as a user interface, using a set of images and graphical objects to represent the information and actions available in the interface. Its main use consists of providing a simple visual environment to allow communication with the operating system of a machine or computer.

A tooltip (also called a pop-up description) is a visual aid tool, which works by placing the cursor over a graphical element, showing additional help to inform the user of the purpose of the element it is over.

How is it done?

Create a tooltip  in a text of a content will be very simple.


  • We select the text to which to add information and click on the Tooltip icon.
  • We choose one of the two available options:
    • Link: to include a hyperlink
    • Definition: to add text
  • We fill in the requested data
  • In the other tabs we can configure the behavior of the tooltip and its appearance
