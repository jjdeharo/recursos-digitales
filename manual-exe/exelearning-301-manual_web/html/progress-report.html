eXeLearning 3.0.1 Manual

Progress report

What is it?

This iDevice shows the results obtained by the students in the activities associated with it and their average grade. 

With this iDevice, we can collect the grades of the activities we select and present them in a final report that can be saved as an image. Simply enter an identifier (a number or a word of more than four characters) both in the report and in each of the activities we want to include in it.

How is it done?

When selecting the "Progress Report" iDevice from the list of iDevices, the following will be displayed in our eXeLearning:

At the top, we will have the option to modify the title and assign an icon, once the iDevice is saved. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our report.

General Settings

In the "Options" section, we will enter the identifier that determines which activities will appear graded in the report. Previously, we will have entered this same identifier in those activities. We will also add the number of evaluable activities. Furthermore, we can configure this report with different options: show date and time, show the iDevice type, link the activities, and enter user data.
