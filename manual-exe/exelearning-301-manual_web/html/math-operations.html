eXeLearning 3.0.1 Manual

Math operations

What is it?

We will use this iDevice to create activities with basic mathematical operations (addition, subtraction, multiplication and/or division) random ones in which the student will have to figure out the result, the operator, or one of the operands.

Given the flexibility of this iDevice, we will be able to define:

  • Whether we want the student to guess the result, the operator, the first or second operand, or any of the above.
  • The highest and lowest number, the number of operations, and the decimals
  • The errors (relative and/or absolute)

How is it done?

When selecting the "Mathematical Operations" iDevice from the list of iDevices, the following will be displayed in our eXeLearning:

At the top, we will have the option to modify the title and assign an icon, once the iDevice is saved. Finally, we will have the option to include subsequent content. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Settings


The "General Settings" tab is the one displayed by default when creating the Mathematical Operations iDevice.

In this tab we will define the instructions for playing the game, the different options and configurations available, and the questions with the clues we determine.

  • When clicking on the "Instructions" section, a text box will open where we can state the instructions to follow.
  • By clicking on the "Options" section we can decide:
Without activating the "Fractions" checkbox (Elementary Operations)

The element to guess: result, operator, operands, and random, the number of operations to perform and number range, the number of decimals in the operands, the type of operation (additions, subtractions, multiplications, divisions), and various options such as allowing decimals in results, negatives, zero, errors... Similarly, we will be able to limit the time for completing the activity.
There is also the option to mark the Progress Report with its corresponding identifier.

    Activating the "Fractions" checkbox (Operations with Fractions)

    The element to guess: result, operator, operands, and random, the number of operations to perform and number range, the number of decimals in the operands, the type of operation (additions, subtractions, multiplications, divisions), and options such as allowing negatives or the irreducible fraction. We will be able to limit the time for completing the activity and there is the option to mark the Progress Report with its corresponding identifier.

    Passwords

    In the "Passwords" tab, we can create a challenge itinerary where players cannot access a new game until they obtain a key in a previous activity. For this, we can set an access code as well as a message that will be shown to players when they reach a fixed percentage of correct answers, and which they can use as a password for a new challenge or a subsequent activity. 

    Both are optional, and their configuration will only appear if we mark them, as in the image.

    SCORM

    In the "SCORM" tab, we can determine whether we want to save the results obtained by our students and under what conditions we want to do so when we export our content.

    It should be noted that this save option will only be available for SCORM exports and when we publish our content on platforms such as Moodle or other SCORM-compatible LMS platforms.

    Custom texts

    Tab where we can customize the texts and automatic messages generated by the iDevice.
