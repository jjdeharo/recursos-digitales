eXeLearning 3.0.1 Manual

Link

What is ?

We can insert a link to a website or to a file:

  • Link to website: Cedec
  • Link to document: Oral presentation evaluation rubric (pdf - 106.12 KB)

How is it done?

Link to website



To insert a link to a website, we click on the icon  and write the corresponding link in the field Source.

For accessibility, it is important to fill in the field Title (for example, "Link to website. Opens in new window") and the field Open link in (select "New window")

Link to document

In case we want to link a document, we will have to search for and select it on our computer with the "Browse" button.

Additionally, we have the option to include additional information such as size and extension by clicking on Include file information.
