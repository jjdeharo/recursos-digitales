eXeLearning 3.0.1 Manual

Form

What is it?

We will use this iDevice to ask questions in various ways, all of which can be interspersed in the same "Form". So we have:

  • To create questions that must be answered with "True" or "False". 
  • To propose to the students a text with blank spaces that must be completed. ( "Fill in the gaps" ).
  • To offer the students a text with a list of possible word strings that must be selected. We will have the possibility to add new words (separated by "|" in the corresponding box) to increase the possible answers. ("Dropdown")
  • To propose one (or several) multiple-choice questions ("Selection") to the students. Each of the questions can only have one correct answer ("Single" mode) or several ("Multiple")

How is it done?

When selecting the "Form" iDevice from the list of iDevices, various options will be displayed to us

At the top, we will have the option to modify the title and assign an icon, once the iDevice is saved. Finally, we will have the option to include subsequent content. We see that there are a series of options and tabs, each with a different functionality that will allow us to configure our game in a very flexible way

General Settings

The "General Settings" tab is the one displayed by default when creating the Form iDevice.

In this tab we will define the activities proposed in the iDevice, instructions and options, as well as the questions that our students must answer in this form.

  • When clicking on the "Instructions" section, a text box will open where we can state the instructions to follow.
  • By clicking on the "Options" section, we can configure the maximum time we give our students to answer the questions, the percentage of questions to show, show the solutions in each question, as well as whether we want to shuffle the questions in each execution. It is also possible to mark the Progress Report with its corresponding identifier.
  • In the "Questions" section, we find the possibility to add questions of "True or False", from "Fill in the gaps", in the form "Dropdown" and "Selection". The latter can have one correct answer ("Single" mode) or several ("Multiple" mode).

SCORM

In the "SCORM" tab, we can determine whether we want to save the results obtained by our students and under what conditions we want to do so when we export our content.

It should be noted that this save option will only be available for SCORM exports and when we publish our content on platforms such as Moodle or other SCORM-compatible LMS platforms.

Custom texts

Tab where we can customize the texts and automatic messages generated by the iDevice.

Import/Export

In the "Import/Export" tab we can import questions compatible with this activity from txt or xml files (Moodle), or we can export the questions in txt format to integrate them into other compatible activities.

AI

This tab allows bringing questions from an AI chatbot in a simple way. When opened, it shows us, as an example, a Prompt (model) that we can take to a chatbot which will generate the questions in the appropriate format to be pasted into the "Questions" tab. These questions proposed by the AI will be added to the iDevice when we save them, ready to be used in the activity.
