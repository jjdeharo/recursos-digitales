eXeLearning 3.0.1 Manual

Publication

The .elpx files created with eXeLearning 3.0 have a significantly different structure from the .elp files generated with eXe 2.9 and earlier versions. As it is a recently released version, many platforms and web environments are not yet prepared to work with this new file structure. However, it is expected that, over time, these platforms will be updated to offer compatibility.

Meanwhile, we can use some alternatives that are already compatible, such as Moodle.

Below, these currently available options are explained. This list will be updated as new compatible platforms emerge.

NOTICE: The Procomún repository and the eXeReader application for mobile devices, used for managing and viewing content created with eXeLearning 2.9, are not yet compatible with content generated in version 3.0 of eXeLearning. This compatibility will be enabled soon, and at that time this manual will be updated with the corresponding instructions.

Publish to Moodle

We can upload content created with eXeLearning to a Moodle platform in different formats, such as Website, SCORM, or IMS Content Package. Furthermore, if the Moodle platform has the online version of eXeLearning integrated via the eXeScorm and/or eXeWeb plugins, it is possible to create and edit content directly from the LMS, without needing to leave the platform.

In either case, we must be clear about the format in which we are going to present the materials in Moodle: SCORM, IMS, or Website.

  • SCORM: If we want to save the notes from the iDevices that have that option and track the pages viewed by the students. We recommend exporting in SCORM1.2 since Moodle does not currently support SCORM2004.
  • IMS: If we only want to display the content but want that package to retain its metadata when uploaded to Moodle.
  • Website: If we only want to display the content and do not need metadata. This is the most recommended option if we have not used the iDevices mentioned above, as it offers a more attractive display as we can see below.

Publishing content created with eXe in Moodle

In this case, we are going to upload to Moodle content previously created in eXeLearning and exported as SCORM1.2, IMS, or website.

Publication as SCORM

STEPS:

  1. We add a "SCORM package" activity.
  2. We fill in the data and upload our SCORM package.
  3. We save.
  4. To view it, we click on the activity title and then on the Enter button. Moodle will use its own SCORM viewer to display the resource, so the appearance may differ from how it originally looked in eXeLearning.

We remind you that Moodle does not support SCORM2004, so we recommend doing the export to SCORM 1.2.

Publication as IMS

STEPS:

  1. We add an "IMS Content Package" resource.
  2. We fill in the data and upload our IMS file.
  3. We save.
  4. To view it, we click on the resource title. Moodle will use its own IMS viewer to display the resource, so the appearance may differ from how it originally looked in eXeLearning.

Publication as Website

STEPS:

  1. We add a "File" resource.
  2. We fill in the data and upload our Website file (.zip). 
  3. We click on the uploaded file. In the window that appears, we click on Unzip. A series of files and folders will appear.
  4. We click on the file index.html and, in the window that appears, we click on Set as main file.
  5. We save
  6. To view it, we click on the resource title. In this case, we will see all the content with the menu and style defined in eXeLearning. 


Create and/or publish in Moodle with eXe plugins

The eXe plugins for Moodle facilitate the creation, modification, and publication of content from the LMS itself. The code for these two plugins (one for SCORM content and one for content in Website format) is published in the official Github repository. To use them, it is necessary to have an instance of eXe online, a Moodle platform, and the plugins installed.

The operation is very simple. 

To create content with eXeLearning from Moodle, we will enter a course within our platform and follow these steps:

Step 1


We add an activity of type "eXeLearning (SCORM)" or "eXeLearning (Website)".

Step 2

We write a title and leave the option "Create with eXeLearning" selected. If needed, we can edit the configuration options (appearance, grades...). When clicking "Save and display," eXe online will open and we can create our material.

Once we have finished editing the material, we will click on the Finish button (located at the top right) and it will be available in our course. 

Step 3

If we need to modify or continue with the editing, we will enter the resource and click on the "Edit with eXeLearning" button.

Step 4

We also have the possibility to publish and modify the package created with eXeLearning instead of creating it from scratch. To do this, once the "eXeLearning (SCORM)" or "eXeLearning (website)" activity is selected, we will choose the "Uploaded package" option in the "Package" field.
