eXeLearning 3.0.1 Manual

Image gallery

What is it?

We will use this iDevice to display an image album, initially in thumbnail format. Clicking on any of the images in the album will open an enlarged sample, with the possibility of navigation between the different images in the gallery.

Usage example

Idevice Example template start
Idevice content start
Idevice content end
Idevice Example template end

How is it done?

 When selecting the "Image Gallery" iDevice from the list of iDevices, the following will be displayed in our eXeLearning:

Add images from the button Add images.

Once the first one is added, you can continue adding (or dragging from a folder), deleting and moving from the buttons below each one. Remember to write a descriptive text for each.
