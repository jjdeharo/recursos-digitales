eXeLearning 3.0.1 Manual

Mind map

What is it?

With this option we can create simple mind maps. Starting from a word or idea, we can add as many nodes and subnodes as we want. We can also configure the font and line format. Before incorporating it into our material we will have to give it a name and we can crop the image.

How is it done?

  • When clicking on the Mind map icon  a first window appears with the map data (Title, dimensions, options...). Once filled, we will click on "Open the mind map editor".
  • Next, we can create our mind map. Starting from the central idea (which we can rename by double-clicking) we will create as many branches as we want. We can create and delete branches with the Add and Delete buttons. Also, from the Inspector panel we can modify the text size, style and color, as well as the line color.
  • When saving we can decide whether to crop the image and define the proportion.
  • Finally, we will return to the initial window and click Accept.
