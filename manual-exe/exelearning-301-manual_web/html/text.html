eXeLearning 3.0.1 Manual

Text

What is it?

This is the most used iDevice as it will allow us to add content using a text editor. We will use it mainly to present a topic and display the content.

This iDevice has been "expanded" to perform the functions of the old Task iDevice from eXeLearning 2.9 and now optionally it can include the estimated duration of the task and the number or description of participants involved.

Usage example

Simple Text iDevice

Text iDevice with title, icon, and feedback

How is it done?

When selecting the "Text" iDevice from the iDevices list, the following will be displayed in our eXeLearning:

In the central text field, we will enter our content (text, images, links, videos, etc.). Optionally, we can add:

  • A title, which can be added once the iDevice is saved
  • An icon to choose from those available for the selected style. Also after saving.
  • Information, in case the text is a task, about its duration and possible groupings to carry it out
  • A feedback section that will expand when clicking the button (the button text is also editable)

All the possibilities of the Text Editor have been previously covered in this manual.
