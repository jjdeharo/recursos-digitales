eXeLearning 3.0.1 Manual

Insert HTML as text

What is it?

The button expands the possibility of presenting HTML (and more programming languages) as text.

HTML dark syntax highlighting

<head>
    <title>Example</title>
  </head>

Javascript

<style>                            
body {
    display: flex;
    justify-content: center;
}
</style>

How is it done?

The I buttonInsert HTML code as text  allows, in addition to inserting code to display it in the document, highlighting its syntax with colors (accepts different languages), highlighting lines, and selecting the appearance.
